# CodeAlpha Python Projects

This repository contains Python projects completed as part of the CodeAlpha Internship.

## Project 1: Hangman Game

### Description
A simple text-based Hangman game built in Python. The player guesses a hidden word one letter at a time. The game ends when the player guesses the word or makes 6 incorrect guesses.

### Features
- 5 predefined words
- Random word selection
- Maximum of 6 incorrect guesses
- Console-based gameplay

### File
- hangman.py

## Project 2: Rule-Based Chatbot

### Description
A simple rule-based chatbot built in Python. The chatbot responds to predefined user inputs such as "hello", "how are you", and "bye".

### Features
- Predefined responses
- Uses functions
- Uses if-elif statements
- Uses loops and user input

### File
- Chatbot.py
